
# Paradise Nursery 🌿

Paradise Nursery is an online houseplant shopping application built with React and Redux Toolkit. It allows customers to explore plants, add items to their cart, adjust quantities, and calculate their total order cost.

## Features
- Responsive landing page with a Get Started button
- About Us section describing the company
- Three categories with six unique plants per category
- Plant thumbnails, descriptions, and prices
- Add to Cart buttons that disable after adding a plant
- Navigation for Home, Plants, and Cart
- Dynamic cart item count
- Increase/decrease quantity and remove items
- Automatic item subtotals and cart total
- Checkout message: Coming Soon
- Continue Shopping button

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- CSS

## Getting Started
Install dependencies using `npm install` and start the development server using `npm run dev`.

## Project Files
- `src/App.jsx` — application layout and landing page
- `src/App.css` — landing page background and styling
- `src/AboutUs.jsx` — company information
- `src/CartSlice.jsx` — Redux cart state
- `src/ProductList.jsx` — categorized plant catalogue
- `src/CartItem.jsx` — shopping cart page
- `src/store.jsx` — Redux store configuration
- `src/main.jsx` — React entry point
